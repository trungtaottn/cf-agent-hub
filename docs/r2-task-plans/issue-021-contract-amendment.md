## Import contract decisions

1. Separate raw-envelope admission from independent closed row validation. Strict ImportBatch describes wholly valid data, while ImportEnvelope admits invalid row values for indexed rejection. Source references stay inert. UTC accepts Z/z and +00:00; -00:00 is rejected.
2. Preview row dispositions are create/unchanged/conflict/rejected; report rows explicitly use created/unchanged/conflict/rejected. Counts partition received exactly, with contiguous ordered indices. All disclosed duplicate external-ID occurrences conflict with DUPLICATE_EXTERNAL_ID, never first-row-wins creation. Invalid or inaccessible rows retain generic rejection/null identifiers.
3. The original abbreviated report rows omitted the explicit provenance exposure required by Task 9. Resolve that gap with a closed provenance field on report rows: mandatory ImportProvenance for authorized created/unchanged rows, null for conflict/rejected rows. This records the current attempt's source revision without rewriting an unchanged task/mapping. Task DTO remains byte-for-byte equivalent.
4. Public preview SHA-256 uses repository canonicalJson semantics over all public fields except preview_sha256. Full strict ImportRow hashes exclude batch source_revision metadata. Public digest alone does not hash omitted source bodies or confer authority: preview ID immutably binds original source and mapping/reference snapshots internally. Do not replace snapshots under the same ID.
5. Check current owner/workspace/scopes/reference visibility before disclosing or classifying mappings. Inaccessible/absent references share INVALID_REFERENCE. Deny an immutable saved plan/report that is no longer safely visible rather than silently redact it. Rejected rows never echo external IDs, task IDs, provenance, unknown fields or raw schema errors.
6. Exact 900-second expiry and false partial acceptance with conflict/rejection yield INVALID_STATE. Digest/version or mapping/reference snapshot changes yield whole-apply VERSION_CONFLICT. Valid new rows always become Backlog without imported authority. All selected writes/report/events/audit/replay belong to one future transaction.
