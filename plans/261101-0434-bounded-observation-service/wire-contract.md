If expected session was replaced/reused, do not return new rows: VERSION_CONFLICT with no protected replacement identifiers. Reopen without expected_session_id is an explicit current-view query. No retained data does not mean no external activity.

## Error semantics
Reuse existing closed error envelope, never invent a successful partial body:
-401 malformed/unavailable verified credential/session, consistent existing native ingress.
-403 current scope/resource/runtime proof failure; do not distinguish guessed foreign session existence.
-400 invalid closed body/query/path/unsafe integer;413 request-byte oversize.
-409 STALE_RUN after authorized exact-run guard rejects lease/run/fence;409 VERSION_CONFLICT for authorized current-session/highwater CAS mismatch;409 IDEMPOTENCY_CONFLICT for a retained same operation/range identity with changed body.
-409 LIMIT_EXCEEDED for metadata capacity/sequence overflow/single admitted batch cannot fit after permissible eviction.
-410 CURSOR_EXPIRED for expired otherwise valid cursor; invalid binding remains existing400 behavior.
-503 DEPENDENCY_UNAVAILABLE for disabled pilot/current admission unavailable or changed read between async cursor encryption and final authorization check, without new resource detail.
No4xx received after an uncertain earlier diagnostic request proves that earlier request did not commit. Keep UNKNOWN until exact retained matching receipt; no retries of domain operations.

Same replacementretry after appendS2 -> originalS2receipt plus no counter reset; status separately shows current highwater.

Ordinary DOrestart -> state preserved; actual restore/configgeneration reset -> both diagnostic tables invalidated, current authority cannot resurrect previoussession.

### Canonical path and cursor-cap closure
Repository-relative reported paths preserve case and exact Unicode code points (no silent NFC/case folding). Reject leading/trailing slash, empty path segments, `.`/`..` segments, backslash and NUL; no URL decoding of submitted JSON path and no absolute/drive/UNC form. New-file names remain valid without existence claims. This is display/correlation syntax, NOT symlink resolution or filesystem mediation. Canonical JSON encodes the validated path without changing its value before fingerprinting.

Existing opaque IDs are not retroactively truncated to fit cursors. Before encryption, compute complete padded cursor cleartext size against existing1508bytes; if the authorized binding cannot fit, return bounded LIMIT_EXCEEDED rather than malformed token or silent truncation. No new global ID maximum or changed legacy cursor behavior. Observation response serialization separately checks existing1MiB response cap before returning; exact accepted maximum fixtures must account for JSON escaping and envelope/receipt overhead, not just raw path lengths. Typical positive max-page fixtures and oversized binding/error negatives are B1 tests.

### Whole-observation operational deadline
Each admitted observation operation has a fixed5000ms operational deadline from work-reservation acquisition, independent of task lease, approval expiry or receipt retention. It is an availability/work bound, never authority renewal and not a strict CPU-wall-clock claim on Workers. Race every pending body read and asynchronous cursor/hash step against the same abort/deadline signal; check it again after synchronous parse/serialization and immediately before the final transaction/response authorization guard. On deadline return generic503 DEPENDENCY_UNAVAILABLE, cancel the body reader and release owned reservation in finally; never wait indefinitely for an underlying stream's cancel promise. Late completions are generation-fenced and cannot write or publish a response. Native uncancellable crypto uses bounded input and must retain its internal work accounting until settlement even if the HTTP response has timed out; request timeout is not permission for unbounded concurrent orphan crypto. Four held bodies must time out/release, while4held crypto work allocations reject new work until settled; ordinary domain heartbeat remains independent. Tests distinguish never-resolving body read, cancellation callback that never settles, held crypto completion and timer-delayed execution. This deadline does not declare any prior uncertain append uncommitted.
